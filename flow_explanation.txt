==========================================================
     PORTFOLIO BUILDER APPLICATION FLOW EXPLANATION
==========================================================

This document explains exactly how the Frontend flow of the application is working step-by-step.

1. STARTING POINT: main.jsx
----------------------------------------------------------
- The application starts execution from `src/main.jsx`.
- It wraps the entire application inside the `<AuthProvider>` context. This ensures that every component and page in the app knows if a user is logged in or not.
- It then renders the `<App />` component.

2. GLOBAL LAYOUT AND ROUTING: App.jsx
----------------------------------------------------------
- `src/App.jsx` handles the main layout and all the routing logic using `react-router-dom`.
- The layout is structured vertically:
    [ Navbar ]   -> from src/components/Navbar.jsx
    [  Page  ]   -> Inside the <Routes> container
    [ Footer ]   -> from src/components/Footer.jsx
- No matter which page you visit, the Navbar always stays on top and the Footer stays at the bottom. The content in the middle changes based on the URL.

3. DYNAMIC NAVIGATION: Navbar.jsx
----------------------------------------------------------
- The Navbar contains static links on the left: Home (`/`), About (`/about`), and Contact Us (`/contact`).
- On the right side, it listens to the AuthContext:
   -> If the user is NOT logged in: It shows [Login] and [Register] buttons.
   -> If the user IS logged in: It greets the user ("Hi, User"), shows a [Dashboard] link, and a [Logout] button.
   -> Depending on the user's role (Admin vs Regular User), the Dashboard link goes to either `/admin` or `/dashboard`.

4. PAGE RENDERING (Depending on the route)
----------------------------------------------------------
- '/'      -> Home.jsx      (Landing page showcasing features)
- '/about' -> About.jsx     (Information about the platform)
- '/contact'-> ContactUs.jsx(Contact form for user inquiries)

- AUTHENTICATION:
- '/login'    -> Login.jsx    (User enters credentials. On success -> redirects to Dashboard)
- '/register' -> Register.jsx (User registers. On success -> redirects to Login)

- USER FLOW:
- '/dashboard' -> UserDashboard.jsx (The logged-in user can view their stats and manage their portfolio link).
- '/create-portfolio' -> PortfolioForm.jsx (User inputs skills, projects, and bio to generate their portfolio).

- PUBLIC VIEW:
- '/portfolio/:userId' -> PortfolioView.jsx (The generated layout of the user's portfolio. Anyone with the link can view this, it does not require login).

5. GLOBAL STYLING: index.css
----------------------------------------------------------
- All pages and components consume styles from `src/index.css` and local CSS files (`PageStyles.css`, `Navbar.css`, etc). 
- `index.css` contains the global definitions (fonts, gradients, colors, glassmorphism cards, premium buttons) which gives the app a unified, sleek, and modern look.

==========================================================
     SUMMARY OF A TYPICAL USER JOURNEY
==========================================================
1. User lands on `/` (Home). Appreciates the beautiful UI. Wants to know more, goes to `/about`.
2. User decides to join, clicks `Register` in Navbar -> goes to `/register`, fills form.
3. User goes to `/login` and logs in.
4. Navbar updates (Login/Register turn into Dashboard/Logout).
5. User is routed to `/dashboard`. 
6. User clicks "Create Portfolio", fills details in `/create-portfolio`.
7. User shares their link `/portfolio/their-id`. Anyone visiting this link sees their beautifully rendered portfolio.
8. User clicks `Logout` -> session clears -> routed back to Home (`/`).
